🅰️ ASCII Project
👩‍💻 About the Project
Hello! I'm Mitali , a BCA 2nd-year student at Dezyne École College, Ajmer. This is my Java-based ASCII Project, created as part of my 3rd semester learning journey in Java programming.

The ASCII Project allows users to print creative and customizable patterns using alphabets, numbers, strings, special characters, and more! It’s a fun and interactive way to understand Java’s logic, loops, and ASCII values.

🎯 Features
🔤 Single Letter ASCII Art 
🧵 Word ASCII Art 
🔤 Alphabet Range Print 
🔢 Number ASCII Art 
🔣 Symbol ASCII Art 
💡  String ASCII Art (Mixed Input)

🛠️ Technologies Used
Language: Java
IDE: Any Java-supported IDE (Eclipse, IntelliJ IDEA, NetBeans, or VS Code)
Concepts Used: Loops, Conditional Statements, ASCII Values, and String Handling
